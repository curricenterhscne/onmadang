# CLAUDE.md — 고교-대학 연계 학점 인정 강좌 (dual_credit/)

> 온마당 공통 헤더/푸터 + `common.css` 토큰만 사용. 강좌 데이터는 HTML 내 인라인.
> 최종 검증 2026-08-20 — `curriculum.html` 신설 · `index.html` 재작성 · `courses.html` 링크 비노출

## 개요

학생에게 노출되는 화면은 **두 개**다.

| 노출 | 파일 | 성격 | 바뀌는 주기 |
|---|---|---|---|
| ✅ **과목 교육과정** | `curriculum.html` | 무엇을 배우고 어떻게 평가하는가 (전자책 형태 문서) | 거의 안 바뀜 — 14개 과목 유지 |
| ✅ **제도 안내** | `index.html` | 학점 인정 방식, 개설 과목 목록, 신청 절차·유의 사항, 문답 | 상시 |
| ❌ 개설 강좌 | `courses.html` | 학기별 운영 일정·장소·강사 | **링크 비노출** (아래 참조) |

수강신청 앱 본체는 **`apply/app.html`**이다 (`apply/index.html`이 아니다 — 자세한 내용은 `apply/CLAUDE.md`).

## 폴더 구조

```
dual_credit/
├─ index.html        ← 제도 안내 (공통 디자인 토큰, details 문답)
├─ curriculum.html   ← 과목 교육과정 문서 (전자책 레이아웃, 원본 문서를 스코프해 이식)
├─ courses.html      ← 강좌 카탈로그 (DATA 배열 인라인) — 현재 어디서도 링크되지 않음
├─ enroll.js         ← 수강 신청 기간 개폐 제어 (index·courses 공용)
└─ support/
   ├─ index.html  ← 수업 운영 안내 협의회 안내 (약 401줄, 공통 헤더 미사용)
   └─ 2026_2학기_수업운영안내협의회_운영계획.pdf
```

> `support/`는 **GNB·본문 어디에서도 링크되지 않는다.** 협의회 참석자에게 URL을 직접 배포하는 페이지다.
> 지운다고 사이트에 죽은 링크가 생기지는 않지만, 외부에 뿌려진 URL이 깨진다.

### ⚠️ `courses.html`은 2026-08-20부터 링크되지 않는다

학생 동선을 **「과목 교육과정」과 「제도 안내」 둘로만** 정리하기로 하여, `courses.html`로 가는 링크를 전부 걷어냈다.
파일과 기능은 그대로 살아 있고 `enroll.js`도 물려 있다. **직접 URL로만 접근한다.**

- 다시 노출하려면 `index.html`의 「개설 과목」 절과 `safety/off-campus_courses.html`의 `.dc-links`에 카드를 추가한다.
- 학기별 운영 일정·장소·강사·준비물은 현재 **수강 신청 시 안내**하는 것을 전제로 문구가 쓰여 있다 (`index.html`의 운영 절차 ②·유의 사항, `curriculum.html`의 `.doc-lead`). 이 페이지를 다시 노출하면 그 문구도 함께 손봐야 한다.

## 문체 원칙 (2026-08-20)

학생·학부모용 문구는 **홍보·설득 톤을 쓰지 않는다.** 건조하고 정중하게 사실만 적는다.

- ❌ "고교 학점과 대학 학점을 동시에!", "대학의 문을 먼저 열고", "나의 꿈에 날개를 답니다"
- ✅ "협약 대학이 개설한 과목을 이수하고 고등학교 학점을 인정받는 제도입니다."
- 느낌표·구호·감탄 표현을 쓰지 않는다. 혜택을 단정하지 말고 조건을 함께 적는다.

## ★ 수강신청 링크 — `enroll.js` 하나만 고친다

**하드코딩된 `../apply/*.html` 링크는 더 이상 없다.** (2026-08-20 이전에는 4곳에 흩어져 있었다.)
신청 기간을 열고 닫으려면 **`enroll.js`의 `OM_ENROLL.periods` 배열 한 곳만** 고친다.

```js
periods: [
  { term: '2027학년도 1학기',
    open:  '2027-02-19T18:00:00+09:00',
    close: '2027-03-05T18:00:00+09:00' }
]
```

- 과거 기간은 **지우지 말고 남겨 둔다.** 지나간 기간은 자동으로 닫힌 상태가 된다.
- 기간이 지나면 신청 버튼은 `href`가 제거되어 눌리지 않고, 문구가 「신청 기간 아님」으로 바뀐다.
- 상태는 색이 아니라 **문구로** 구분된다 (KWCAG). 클래스만 바꾸고 문구를 없애지 말 것.

### 상태 3종

| 상태 | 조건 | 버튼 | 안내 문구 |
|---|---|---|---|
| `open` | 현재가 어느 기간 안 | `수강 신청 →` (`apply/app.html`) | "○○학기 수강 신청을 접수하고 있습니다. 마감 …" |
| `upcoming` | 아직 시작 전인 기간이 있음 | `신청 기간 전` (비활성) | "○○학기 수강 신청은 …에 시작합니다." |
| `closed` | 해당 없음 | `신청 기간 아님` (비활성) | "현재 접수 중인 수강 신청이 없습니다…" |

### 마크업 훅 (`data-enroll`)

| 값 | 대상 | 동작 |
|---|---|---|
| `cta` | `<a>` | `href`·문구·`enroll-open`/`enroll-shut` 클래스 교체 |
| `notice` | 아무 요소 | 상태 안내 문구 주입 |
| `term` | 아무 요소 | 학기 이름 주입 |
| `open-only` / `closed-only` | 아무 요소 | `hidden` 토글 |

- 동적으로 그린 DOM(예: `courses.html`의 상세 모달)에는 **`window.OM_ENROLL_APPLY()`를 다시 호출**해야 반영된다.
- 상태 값은 `window.OM_ENROLL_STATE`로 읽을 수 있다 (`goSignup()`이 이걸 본다).

## curriculum.html — 과목 교육과정 문서 (전자책 레이아웃)

원본: `2026 고교-대학 연계 학점 인정 학교 밖 교육 과목 교육과정.html` (충남교육청 발간 문서).

레이아웃은 `.ebook`(그리드) = **왼쪽 고정 목차(`.ebook-side`, sticky) + 오른쪽 본문(`.doc-wrap`)**.
960px 이하에서는 목차가 본문 위로 쌓이고 sticky가 풀린다.

### 이식할 때 반드시 지킬 것 (셋 다 실제로 깨졌던 항목이다)

1. **원본 CSS는 전부 `.doc-wrap` 아래로 스코프한다.**
   원본의 `.wrap`은 공통 헤더의 `.wrap`(`max-width:var(--maxw)`)과 충돌한다.
2. **원본의 `<header class="c-head">`를 `<div class="c-head">`로 바꾼다.**
   `common.css`가 **요소 선택자** `header{position:sticky;top:0;z-index:100}`을 걸어 두었기 때문에,
   `<header>`를 그대로 두면 과목 제목이 화면 상단에 고정되어 **GNB 위에 겹쳐 보인다.**
   → 외부 문서를 이 사이트로 가져올 때 `<header>` `<footer>` `<nav>` 같은 **요소 선택자 충돌을 먼저 확인할 것.**
3. **원본 표지(`.cover`)는 제거한다.** 제목은 공통 `.page-hero`가 맡고, 목차는 사이드바로 옮긴다.

### 인라인 스크립트가 하는 일

| 기능 | 설명 |
|---|---|
| 표 래핑 | 모든 `.tbl`을 `.tblx`(가로 스크롤)로 감싼다 — 본문이 가로로 넘치지 않게 |
| 스크롤스파이 | 화면 상단 120px 기준으로 현재 과목을 판정해 목차에 `aria-current="true"` 부여, 목차를 따라 스크롤 |
| 앵커 재정렬 | 공통 헤더 주입·표 래핑으로 높이가 변하므로 `load` 후 `#course-N`으로 다시 이동. **`behavior:'instant'` 필수** — 로딩 중 smooth 스크롤은 끊긴다 |

### 과목 번호

과목 앵커는 **`#course-1` ~ `#course-14`**이며 `courses.html`의 `DATA[].연번`과 **순서가 일치한다** (실측 확인).
→ 순서를 바꾸면 `index.html` 과목 표의 링크와 `courses.html` 모달의 「교육과정 보기」가 어긋난다.
셋(`curriculum.html` 목차 · `courses.html` DATA · `apply/_embed_data.js`)을 함께 볼 것.

### 서브 배열: 강사

```json
[{"성명": "김이영", "소속": "국립공주대학교", "전공": "교육심리상담"}]
```

### 서브 배열: 일정 (수업 일정 테이블용)

```json
[{"date": "2026-09-05", "요일": "토", "시작": "13:00", "종료": "16:50", "차시수": 4}]
```
- `buildScheduleHTML()`이 이 배열로 수업 일정 테이블 렌더링
- `시작`/`종료`가 비면 "수업 시간" 열이 공란으로 표시됨

### 서브 배열: 차시 (차시별 수업 계획 테이블용)

```json
[{"차시": 1, "일자": "2026-09-05", "시작시간": "13:00", "내용": "과목 목표...", "담당강사": "김이영"}]
```

## apply/_embed_data.js와의 관계

**동일한 14개 강좌**가 두 파일에 각각 존재한다 (필드명이 다름).
강좌 데이터 수정 시 **반드시 양쪽 동시 수정** 필요.

| 이 파일 (courses.html) | apply/_embed_data.js | 비고 |
|---|---|---|
| `DATA[].강좌코드` | `COURSE_DETAILS[].code` | 동일 값 |
| `DATA[].일정` | `COURSE_DETAILS[].scheduleByDay` | 필드명 다름 |
| `DATA[].차시` | `COURSE_DETAILS[].sessions` | 필드명 다름 |
| `DATA[].강사` | `COURSE_DETAILS[].instructors` | 필드명 다름 |
| `DATA[].수업요일시간` | `COURSE_DETAILS[].period` | 필드명 다름 |
| `DATA[].비고` | (없음) | courses.html 전용 |

## 주요 함수 (courses.html — 실측 8개)

| 함수 | 역할 |
|---|---|
| `render()` | 필터(대학·계열·수업방식·검색어) 적용 후 카드 그리드 렌더링 |
| **`openModal(idx)`** | `DATA[idx]`로 상세 모달 렌더링. 카드의 `onclick`에서 호출 |
| `closeModal(e)` | 오버레이 클릭 / ESC로 모달 닫기 |
| `buildScheduleHTML(schedule)` | `일정` 배열 → 수업 일정 테이블 HTML |
| `toggleField()` / `setInst()` / `clearFields()` | 필터 UI 조작 |
| `goSignup()` | `OM_ENROLL_STATE`를 보고 신청 기간이면 앱으로, 아니면 `./index.html`로 이동. **호출하는 곳은 현재 없다** (링크는 `data-enroll="cta"`가 처리) |

> ⚠️ 이전 문서에 `openDetail(idx)`로 적혀 있었으나 **그런 함수는 존재하지 않는다.** 실제 이름은 `openModal(idx)`이다.

## 하지 말 것

- DATA 배열만 수정하고 apply/_embed_data.js를 빠뜨리기 ❌
- `일정`의 `시작`/`종료` 없이 `차시`의 `시작시간`만 채우기 ❌ (둘 다 채워야 함)
- index.html의 통계 수치(대학 수, 과목 수 등)를 DATA와 불일치시키기 ❌
- **`../apply/app.html`을 HTML에 직접 하드코딩 ❌** → `enroll.js`의 `periods`만 고친다
- **`enroll.js`의 지난 기간을 지우기 ❌** → 지나간 기간은 자동으로 닫힌 상태가 된다
- **`curriculum.html`의 `.doc-wrap` 스코프를 풀기 ❌** → 공통 헤더의 `.wrap`과 충돌한다
- **이식 문서에 `<header>` 요소를 남기기 ❌** → `common.css`의 `header{position:sticky}`가 걸려 GNB를 침범한다
- **특정 학기 날짜를 페이지 본문에 다시 박아 넣기 ❌** → 과목은 매년 1·2학기에 다시 열린다
- **`index.html`에 자체 색상 팔레트(navy/gold 등)를 다시 도입 ❌** → `common.css` 토큰만 쓴다. 2026-08-20에 걷어냈다
- **홍보·설득 톤으로 문구 쓰기 ❌** → 위 「문체 원칙」 참조
- 이 문서의 함수명·필드명을 확인 없이 신뢰하기 ❌ → 코드를 열어 대조할 것
