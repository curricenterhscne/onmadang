# 2026학년도 여름방학 꿈키움 출석부 웹뷰어

## 구성
- `index.html` — 메인 페이지 (이 파일만 열면 됩니다)
- `pages/` — 159개 출석부 페이지 이미지 (강좌당 2쪽, 63번 강좌만 3쪽)

## 사용법
1. `index.html`과 `pages` 폴더를 같은 위치에 유지한 채로 웹서버에 업로드
2. 왼쪽 목록에서 강좌명 / 대학명 / 강좌코드(DC26B001~089)로 검색 가능
3. "번호순 / 대학순 / 코드순" 버튼으로 목록 정렬 방식 전환 가능
4. 강좌를 클릭하면 오른쪽에 해당 출석부 이미지가 표시됨
5. 강좌가 2쪽 이상인 경우 상단 탭으로 "명단" / "출석기록" 전환 가능
6. 좌우 방향키로 강좌 간 이동 가능 (검색/정렬 결과 기준으로 이동)

## 강좌 코드 매칭 방식
- PDF상의 강좌 순서는 강좌 코드(DC26B###) 순서와 정확히 일치하지 않습니다.
  (예: 선문대학교 소속 강좌들은 PDF에서 코드 순서와 다르게 배열되어 있음)
- 이 때문에 각 강좌의 원본 이미지를 직접 확인하여 79개 전부 강좌 코드·강좌명·대학명을
  1:1로 정확히 매칭했습니다. 제공해주신 79개 강좌 목록과 대조 검증 결과 79개 전부
  코드·강좌명·대학명이 정확히 일치함을 확인했습니다.
- 63번 강좌(백석문화대학교, DC26B069)는 학생 수가 많아 원본이 3쪽으로 구성되어 있어,
  다른 강좌(2쪽)와 다르게 3개 탭이 표시됩니다.
