# 07 — 1단계 자기 이해 (뷰 4종)

`design/CLAUDE.md`·`design/PLAN.md`·WORKLOG를 읽어라.

views/에 추가 (라우트·데이터·store 경로는 design/CLAUDE.md 표 기준):
1. self-prologue — strengths.json: 강점 35개 탭 선택 그리드, 문장완성 4문항, 배움서약 3줄. 입력 즉시 store.save.
2. self-tests — 유형 설명 카드 탭 3개(흥미 6유형/적성 12영역/가치 12개+4지향) + 각 검사 "커리어넷에서 검사하기"(external-sites.json, 새 탭 — 검사 재구현 금지) + 결과 기록 폼(흥미 1~6순위·T점수, 적성 상·하위, 가치 상위3·지향유형·희망직업 실현가치).
3. self-jobs — 관심 직업 카드 3종(직업명/핵심능력/관련학과/하는 일/임금/준비/자격증) + 직업별 미래 변화 예측 + 깨달은 점.
4. self-summary — step1 전체를 읽기 전용 자동 취합한 종합점검표 + 결론 입력("탐색 결과를 종합할 때, 관심 직업(학과)은 ___이다"). 빈 항목은 해당 라우트 바로가기 링크.

모바일 우선: 카드당 1~2필드 세로 흐름, 긴 폼은 섹션 아코디언. 완료 기준: Step1 진행률·요약 일치, 왕복 저장 무손실 유지. 커밋 전 멈추고 보고.
