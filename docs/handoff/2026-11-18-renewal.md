## 1. 다른 컴퓨터에서 시작하기

저장소 셋을 같은 상위 폴더(`curricenter.hs.cne/`)에 둔다.

```bash
git -C onmadang pull            # 없으면: git clone https://github.com/curricenterhscne/onmadang.git
git -C enrollment_cne pull      # 온라인 공동교육과정 신청 사이트
git clone git@github-work:curricenterhscne/cne-design-system.git   # 디자인 시스템 (없을 때만, 있으면 pull)
```

- **푸시 계정 주의**: `cne-design-system`·`enrollment_cne`는 업무용 SSH 별칭 `git@github-work:`로 올린다. `gh` 로그인 계정(개인)은 DS 저장소에 읽기만 된다. `~/.ssh/config`의 `Host github-work`(키 `id_ed25519_work`)가 그 컴퓨터에 있어야 한다.
- **Claude 스킬 설치**(컴퓨터마다 한 번): `cp -R cne-design-system/claude-skill/onmadang-design-system ~/.claude/skills/` — 자세한 것은 `cne-design-system/claude-skill/README.md`.
- **Supabase CLI**: 함수 배포 때만 필요하다. 별도 터미널에서 `npx supabase login`(대화형). 배포 명령은 `--project-ref yhrgvnttjlitukrxdfdo --yes`를 붙인다(CLI 3.2는 운영 배포에 확인 플래그를 요구한다).
- **로컬 확인**: 레포 루트에서 `python3 -m http.server 8080`. 성능은 `npx lighthouse@12.2.1 <주소>`(크롬 필요).
