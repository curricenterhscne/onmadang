## 1. 노트북 준비

저장소는 둘이다. 같은 상위 폴더에 나란히 둔다.

```bash
git clone https://github.com/curricenterhscne/onmadang.git
git clone https://github.com/curricenterhscne/enrollment_cne.git
```

이미 받아 둔 폴더가 있으면 각 폴더에서 `git pull`. 두 저장소 모두 `main`에서 작업한다(다른 브랜치는 2026-11-16에 정리했다).

| 필요한 것 | 용도 | 비고 |
|---|---|---|
| Git, 브라우저(크롬) | 공통 | |
| Python 3 | 온마당 로컬 확인 `python -m http.server 8080` (레포 루트) | `fetch`를 쓰는 페이지는 `file://`에서 안 열린다 |
| Node.js 22 이상 | `enrollment_cne` 빌드·로컬 실행 | 데스크탑은 24 |
| Supabase CLI | Edge Function 배포 | `npx supabase login` (대시보드의 Access Token) |

`enrollment_cne` 로컬 실행:

```bash
cd enrollment_cne
npm install
# .env 를 만든다 (git 제외 파일)
#   VITE_SUPABASE_URL=https://jrndddwypckotcpipsjc.supabase.co
#   VITE_SUPABASE_ANON_KEY=<공개용 anon 키 — onmadang/assets/js/enroll-status.js 의 ON_KEY 값과 같다>
npm run dev        # http://localhost:5173
```

**데스크탑에만 있고 git으로 오지 않는 것**

- Claude Code 메모리(이전 세션 기록) — 이 문서와 `WORKLOG.md`가 대신한다. 메모리 사본을 따로 옮겨 왔다면 노트북의 `~/.claude/projects/<이 레포 경로로 만든 폴더>/memory/`에 넣는다.
- `design-source/`(업체 원본, git 제외)와 업무 폴더의 업체 회신·운영 매뉴얼 docx — 필요하면 따로 옮긴다.
- 관리 화면 로그인 상태, Supabase CLI 로그인 — 노트북에서 다시 로그인한다.

- 커밋·푸시는 담당자 승인 후에만 한다. 두 저장소 모두 같다.

- 온라인 신청 사이트의 `get_enroll_status()` 이름·반환 모양을 바꾸면 온마당 `assets/js/enroll-status.js`도 함께 고친다.
