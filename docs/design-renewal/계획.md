## 1. 현재 레포와의 관계 (실측)

- 슬롯 시스템(`slots.js`/`manifest.json`)은 **없다**. 2026-07 전략 수정으로 폐기됨. → 이미지 경로를 HTML/CSS에 직접 쓴다.
- 본체 토큰은 `assets/css/common.css` `:root` (`--bg --brand --brand-d --accent --ink --line …`). **이름은 그대로 두고 값만 바꾼다.** 새 역할이 필요하면 같은 규칙으로 추가(`--sky` `--mint` 등).
- `design/majors/`·`design/selector/`는 CDN DS(`--color-*`)를 쓴다 → 이번 단계에서 **건드리지 않는다**. 본체 적용 후 DS v2.0으로 별도 진행.
- 홈 `index.html` 섹션: `hero` → `board-sec` → `about-sec` → `design-sec` → `safety-sec`. 시안 순서는 hero → 고교학점제 안내 → 진로·학업 설계 → 4대 안전망 → 알림·소통 마당 → 푸터. **공지 섹션을 맨 아래로 옮기는 것**이 구조 변경 1건.

## 3. 단계 (각 단계 끝 ⏸ 확인, 커밋·푸시는 승인 후)

1. **점검·매핑 확인** — `점검표`와 `design-map.json`을 실제 파일과 대조, 틀린 곳 수정.
2. **에셋 반입** — `design-map.json`의 `use: true` 파일만 `assets/img/`로 최적화 복사 (SVG: 불필요 메타·`id="_레이어_1"` 제거, 단색 아이콘은 `fill="currentColor"`; PNG: WebP 1440/2880 + 원본 폴백). 원본 덮어쓰기 금지.
3. **토큰 교체** — `common.css` `:root` 값 교체 → 전 페이지 영향 확인(특히 `design/check/` 인쇄, 배지 대비). 명도대비 4.5:1 미달 조합 목록 보고.
4. **홈 리스킨** — 섹션 순서 조정 → 섹션별로 시안과 1440px 스크린샷 비교(`docs/design-renewal/qa/`에 나란히 저장). **기능·링크·문구 데이터는 바꾸지 않는다.**
5. **헤더·푸터·GNB** — 시안 헤더(필 형태 메뉴, 우측 CTA)를 `common.js`/`common.css`에 반영 + 「꾸꾸클럽」 하위 메뉴 추가.
6. **모바일 구현안** — 390px 화면 캡처를 만들어 담당자에게 전달(업체 검토용).
7. **본체 하위 페이지 톤 맞춤** — 토큰 교체로 자연 반영되는 범위 확인, 깨진 곳만 수정.
